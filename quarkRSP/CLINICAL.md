# quarkRSP 义肢/义眼 临床评估方案

> 本文档面向脑意识控制的义肢（EMG 肌电驱动）与义眼（EEG 脑电驱动）系统，
> 作为医疗器械申报（FDA De Novo/510(k)、CE MDR）所需的临床评估前置方案。
> 状态：初稿，需由临床团队、伦理委员会（IRB/EC）审定后实施。

---

## 1. 目的与范围

| 项 | 说明 |
|---|---|
| 目的 | 证明义肢/义眼系统在目标人群中的**有效性、安全性、可用性** |
| 产品 | quarkRSP EMG 义肢控制子系统、EEG 义眼控制子系统 |
| 目标人群 | 上肢截肢/肢体缺失者（义肢）、视力障碍/眼球运动障碍者（义眼） |
| 评估类型 | 探索性临床研究 → 关键性（pivotal）临床研究 |

---

## 2. 评估指标（临床终点）

### 2.1 有效性终点

| 指标 | 定义 | 目标 |
|---|---|---|
| 任务成功率 | 标准抓取/注视任务的完成率 | ≥ 基线 + 有临床意义差值 |
| 完成时间 | 任务完成耗时 | 显著优于基线 |
| 运动精度 | 目标位置/注视方向的偏差 | 误差 < 临床阈值 |
| 意图识别准确率 | EMG/EEG 意图解码正确率 | ≥ 90% |

### 2.2 安全性终点

| 指标 | 定义 |
|---|---|
| 不良事件（AE）率 | 相关 AE / 总使用次数 |
| 严重不良事件（SAE） | 关节超范围运动、误触发致伤等 |
| 急停响应时间 | 从触发到执行器停转的时间 |

### 2.3 可用性终点（IEC 62366）

| 指标 | 定义 |
|---|---|
| 系统可用性量表（SUS） | 标准可用性问卷 |
| 学习曲线 | 达到熟练所需的训练次数 |
| 用户满意度 | 自定义问卷 |

---

## 3. 试验设计

### 3.1 研究设计

- **类型**：前瞻性、单臂或随机对照
- **对照**（义肢）：健康侧肢体、或已上市义肢（如肌电假肢）
- **盲法**：单盲（评估者盲）或开放标签

### 3.2 受试者

| 项 | 说明 |
|---|---|
| 样本量 | 探索性 10-20 例；关键性 30-50 例（按统计功效计算） |
| 纳入标准 | 符合适应症、认知能力可配合、签署知情同意 |
| 排除标准 | 严重认知障碍、植入部位感染、癫痫（EEG 禁忌）等 |

### 3.3 试验流程

```mermaid
flowchart LR
    A["筛选<br/>知情同意"] --> B["基线评估<br/>（无设备）"]
    B --> C["设备适配<br/>（标定/训练）"]
    C --> D["干预评估<br/>（标准任务）"]
    D --> E["随访<br/>（安全性/满意度）"]
```

- **标定阶段**：EMG 电极定位、阈值标定、死区设置（对应 `SafetyController`/`bio_signal.hpp`）。
- **干预阶段**：受试者在监督下完成标准任务集（如「抓取-移动-释放」「注视-追踪」）。
- **数据采集**：同步记录信号、命令、反馈（对应 `HilHarness`）、AE/SAE。

## 4. 风险管理（与 SAFETY.md 联动）

临床研究须基于 `SAFETY.md` 的风险分析（ISO 14971）：
- 每项已识别危险源（H1-H7）须有对应的**缓解措施验证**（如急停响应时间测试）。
- 研究期间发生的任何 AE/SAE 须回填 FMEA，更新风险矩阵。

## 7. 前置待办（临床前必须完成）

1. **HIL 验证通过**：真实设备闭环验证（延迟、一致性、急停）通过 `HilHarness` 报告达标。
2. **动物/台架测试**：如适用，先于人体试验的台架/尸体验证。
3. **软件验证（V&V）**：IEC 62304 对应等级的单元/集成/系统测试覆盖率达标。
4. **EMC/电气安全**：IEC 60601-1 电气安全与电磁兼容测试。
5. **生物相容性**：接触人体的材料生物相容性测试（ISO 10993）。
